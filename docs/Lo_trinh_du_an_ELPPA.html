KẾ HOẠCH PHÂN CÔNG CÔNG VIỆC DỰ ÁN ELPPA (10 TUẦN)

1. THÔNG TIN CHUNG

  • Mục tiêu: Hoàn thiện MVP hệ thống bán điện thoại ELPPA.
  • Nhân sự:
    • Phan Nhật Quang: API Gateway, Auth Service, Product Service, Chat Service, Admin UI.
    • Thái Bảo: Cart Service, Order Service, Notification Service.
  • Thời gian bắt đầu: 26/01/2026.
  • Thời gian kết thúc: 17/05/2026 (Chủ nhật tuần này).
